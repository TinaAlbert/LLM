# Windows重装与项目恢复

公开副本中的`PRIVATE_RUNTIME_DIR`、`PRIVATE_PYTHON_RUNTIME_DIR`、`PRIVATE_SETUP_DIR`和`PRIVATE_CACHE_DIR`均为私有配置占位项，不是已随仓库提供的目录；独立运行目录仍需满足原NTFS/隔离约束。恢复必须先由维护者核对本机私有配置，不把占位路径当作可直接复制的安装命令。

> 公开脱敏说明：本机/服务器位置已改为仓库相对路径或私有配置占位项（`PRIVATE_*_DIR`）；本机私有记录未随仓库发布。原始材料在本机保留，历史命令不构成当前运行或费用许可。

来源：MIG-01保存重装前F盘材料；MIG-02依据2026-10-07用户要求核查重装后的D盘项目，尽可能保留在项目内，并规范必须外放的环境。方法在本文件维护，实际结果、失败和下一操作只查[STATE](STATE.md)。不覆盖未知成果，不初始化替代数据库。

## 目录与Python环境规则

当前项目为 `.`。这块外接盘原来为F，当前为exFAT；不需要改回F。按本轮要求保留项目位置，项目环境也保留在项目内。

| 内容 | 当前位置与管理方式 |
| --- | --- |

| 前端依赖与缓存 | `apps/web/node_modules`；npm缓存与空配置在`.local`，安装器读取`PIP_CACHE_DIR`并显式传`--cache-dir`（本机为`PRIVATE_CACHE_DIR/pip`）；未配置时使用项目`.local/pip-cache` |

通用约定是**一个需要独立依赖的项目一个`.venv`，解释器与下载缓存集中管理**。新项目按`本机私有开发约定文件`使用uv，解释器在`PRIVATE_PYTHON_RUNTIME_DIR`，依赖在项目`.venv`，缓存在`PRIVATE_CACHE_DIR`；不设置全局`PYTHONPATH`或跨项目共享的`UV_PROJECT_ENVIRONMENT`。本项目沿用已锁定、可恢复的3.13.5环境，暂不改依赖管理器或另建C盘venv。多个项目可以复用同版本基础解释器和缓存，不能往共享基础解释器安装各项目业务依赖。归档保留源码、锁、配置与必要结果，普通venv可重建；本次私有恢复包先保留。

## 重建受限外壳与真实验证

D为exFAT，不能承载现有NTFS ACL机制。固定C目录的同范围替代见[决策记录I-11](决策记录.md)，没有新增服务、账户、VHD、capability或loopback豁免。源代码中的`NTFS_RUNTIME`是唯一NTFS路径，不接受请求指定任意可执行文件。

```powershell
if ((Get-Volume -DriveLetter C).FileSystem -ne 'NTFS') { throw 'NTFS runtime unavailable' }
$llmShell = 'PRIVATE_RUNTIME_DIR/shell.exe'
$llmSource = Join-Path $PWD '.local\reinstall\cold-backup\runtime\shell.exe'
if (Test-Path -LiteralPath $llmShell) {
    if ((Get-FileHash -LiteralPath $llmShell).Hash -ne (Get-FileHash -LiteralPath $llmSource).Hash) { throw 'Preserve and inspect differing runtime' }
} else {
    New-Item -ItemType Directory -Path 'PRIVATE_RUNTIME_DIR' -Force | Out-Null
    Copy-Item -LiteralPath $llmSource -Destination $llmShell
}
.\.venv\Scripts\python.exe -X utf8 -m services.guide.manage prepare --authorized-profile-space
.\.venv\Scripts\python.exe -X utf8 -m services.guide.manage probe
```

`location=ntfs`保持不变。prepare只注册专用profile并授固定外壳目录RX，不能证明隔离通过。probe先作废旧报告，需要真实token/SID、零capability、无loopback豁免、存在文件拒绝、在线PG与TCP/UDP4/6宿主控制、受限进程及派生检查。完整证据未通过时观察接口保持503，不回退普通进程。

公网对照必须是现有固定IPv4/IPv6目标的匹配响应；宿主UDP超时或IPv6无路由属于验证前置失败，不能把它标作受限进程阻断，不通过扩大权限或跳过判据凑通过。当前状态与恢复命令查STATE；2026-10-10完整probe已通过，旧网络失败属于历史。报告过期或机制/权限改变后先重新probe，再执行依赖有效证据的正式运行/网页验收；本地子集通过不等于全套通过。重新编译用原`manage build --location ntfs --authorized-profile-space`，然后prepare/probe。
