# D2 本机隔离实施方案

> 公开脱敏说明：本机/服务器位置已改为仓库相对路径或私有配置占位项（`PRIVATE_*_DIR`）；本机私有记录未随仓库发布。原始材料在本机保留，历史命令不构成当前运行或费用许可。

2026-10-07恢复补注：下文F项目/D外壳为原系统历史方案；现项目位于D盘exFAT，固定NTFS外壳改为`PRIVATE_RUNTIME_DIR`，同范围工程取舍见决策I-11，当前运行与验收见[重装恢复](重装恢复.md)/STATE。profile、零capability、无loopback豁免及失败503边界未放宽。


2026-10-01，已实施的本机方案；实际通过数及运行状态仅查STATE。来源：用户本轮D2指令、F10/A09/A11/A14、开发指导D2与附录B、场景设计§3/4/8/10/12–16；仓库外专用空间授权见决策Q6。

本机仓库位于exFAT的F盘，不能依赖NTFS目录ACL。Windows AppContainer API和本机MinGW gcc8.1.0/binutils2.30可用；Docker不可用，WSL未列出发行版。原生外壳编译到授权NTFS目录PRIVATE_RUNTIME_DIR；业务宿主、源码及凭证保留原位。没有增加Python/Node依赖或替换业务技术栈。

使用当前用户专用AppContainer profile `LLM.D2.ReadOnly`（不是新增登录账户/系统服务），零网络capability，未添加loopback豁免。仅继承stdin/stdout两只管道句柄，禁止派生子进程。可信宿主从实际进程token核验AppContainer，而非信任ready文字。外壳无Bearer、DB连接或任意HTTP/SQL/文件工具；只能请求宿主本次委托的kind/object_id。宿主重新授权、投影字段、校验会话/修订后才通过管道发送；返回时只接受相同信封并再次过滤，永不直接交付外壳附加文本。

D2-02进一步从token核验专用SID和零capability，每次读取系统loopback配置确认未豁免。创建时通过JOB_LIST加入宿主独占、不可继承的Job，活动进程上限1、kill-on-close；和派生策略共同防护，不开放breakaway。字节管道有明确长度/队列及读写期限；匹配结果后仍要求EOF与exit=0。正常、恶意输出、阻塞、关闭Job和宿主异常退出的实际验收查STATE与运行测试。

Q6已授权并实际写入的空间：当前用户LocalAppData/Packages的专用profile目录和HKCU登记、PRIVATE_RUNTIME_DIR外壳二进制。仅该目录向专用SID授予RX；不移动业务源码/凭证、不修改其他目录ACL、不修改防火墙或全局Git设置。停止宿主后无常驻助手，保留profile供复用。可用Windows DeleteAppContainerProfile撤除专用登记；删除运行目录前应再次核对绝对路径及内容，不使用泛化清理脚本。

运行环境只传SystemRoot/SystemDrive/windir/USERPROFILE/LOCALAPPDATA/APPDATA/TEMP/TMP路径，不继承业务变量、PATH或Python环境。Windows允许自身系统DLL、该SID可读执行的shell.exe及平台profile空间；不声明整个操作系统零文件可见。没有业务网络允许列表，全部网络不授capability；合法观察经父进程管道。普通执行外壳以11退出，不处理业务信息。

装载修复没有扩大权限：profile准备前错误2；缺系统路径时错误203；旧binutils缺PE重定位表时623；创建控制台时STATUS_DLL_INIT_FAILED (0xC0000142)。当前采用有重定位表的原生二进制、DETACHED_PROCESS及显式管道，避免控制台创建。外壳不依赖.NET。

工程probe首先确认目标文件存在，然后受限进程实际CreateFile打开、不读取内容：业务源码、个人测试答案、网页SQL控制、业务及管理员配置、manage和worker_cli都必须拒绝5。普通宿主必须可连在线PG；回环验证另建临时监听器，宿主连接被接受、受限进程连接超时且未被接受，才结合零capability判定阻断。公网TCP4/6连接必须拒绝10013；UDP按下段收发对照判据单独核验。单独超时、文件不存在、连接被拒绝不能作隔离证据。报告只含类别/拒绝码/哈希/时间及对照结果，无内容、凭证或HTTP响应。

D2-02扩展IPv4/IPv6 TCP、UDP及同一二进制派生对照。TCP外网仍要求10013；UDP采用宿主实际收发、回环/非回环接收器未收到受限数据及公网匹配查询无受限响应的分层证据。sendto成功只表示提交；公网UDP未抓包核验远端送达，不据无响应宣称所有出站数据均被阻断。派生本机367是进程创建被系统阻止，不将它误当可执行文件缺失。报告schema=2绑定二进制和启动器哈希、完整对照、24小时UTC期限；报告缺失/变更/过期和中断失败关闭，没有普通进程回退。协议、错误语义及复现细节单处见运行说明D2-02。

实际进程验收由`tests/business/test_guide_runtime.py`完成，不mock成功，不在无隔离时skip。工程probe模式还可让同一二进制输出恶意请求，测试与生产相同dispatch拒绝伪身份、其他对象、SQL/控制/任意网络文件能力及伪造结果；业务权限反例在实际子进程请求后调用同一可信观察服务，独立SQL比较业务不变。该probe模式无HTTP入口，不授予额外OS权限。

当前范围不涵盖OS内核漏洞、任意DLL注入、全部Windows命名对象/IPC协议、全部IPv6/隧道/广播组合或公网UDP远端收包；未将这些宣称全面渗透测试。未来更换OS、ACL、网络豁免、启动器或二进制后重新probe及专项；不能把本机一次结果推广到其他部署。D2是否通过逐项退出审查只查STATE；模型、D4探索及D5双版本仍分别验收。
